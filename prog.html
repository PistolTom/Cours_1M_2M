⭐️ Exercice 3 : La valeur du milieu

Écrire une fonction milieu qui à partir d'une liste donnée en argument, retourne l'élément qui se trouve au milieu de cette liste. Dans le cas d'une liste de longueur paire, vous choisirez la deuxième valeur parmi les 2 possibles.

Exemples :

  • milieu([8, 0, 100, 12, 1]) -> 100 puisque c'est la valeur qui est positionnée exactement au milieu de la liste.
  • milieu([1, 2, 3, 4]) -> 3 puisque 3 est la deuxième valeur possible pour le milieu.

Exemple de code :


def milieu(lst):
    n = len(lst)
    if n % 2 == 1:
        return lst[n // 2]
    else:
        return lst[n // 2]

# Exemple d'utilisation
print(milieu([8, 0, 100, 12, 1]))  # Sortie : 100
print(milieu([1, 2, 3, 4]))       # Sortie : 3
